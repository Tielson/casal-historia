# Cloudflare R2 storage

Photos and PDF deliverables go through Nest `StorageService` (`@aws-sdk/client-s3`) pointed at an S3-compatible endpoint. Prefer Cloudflare R2 in this project; MinIO remains a local option via `docker compose`.

## Production values (no secrets)

| Item | Value |
|------|--------|
| Endpoint host | `<ACCOUNT_ID>.r2.cloudflarestorage.com` |
| Region | `auto` |
| Bucket | `nos-dois` (aligned with Turso DB naming) |
| Access style | Path-style (`S3_FORCE_PATH_STYLE=true`) |
| Visibility | Private objects; reads via presigned GET (`S3_PUBLIC_BASE_URL` empty) |

## Env keys (Nest `config.s3`)

| Key | Notes |
|-----|--------|
| `S3_ENDPOINT` | `https://<ACCOUNT_ID>.r2.cloudflarestorage.com` |
| `S3_REGION` | `auto` |
| `S3_ACCESS_KEY` | R2 S3 API access key id |
| `S3_SECRET_KEY` | R2 S3 API secret (never commit) |
| `S3_BUCKET` | `nos-dois` |
| `S3_FORCE_PATH_STYLE` | `true` |
| `S3_PUBLIC_BASE_URL` | leave empty |
| `CLOUDFLARE_ACCOUNT_ID` | optional admin |
| `CLOUDFLARE_API_TOKEN` | optional admin (never commit) |

Copy placeholders from `.env.example`. Put real values only in root `.env` and/or `apps/api/.env` (both gitignored).

## Smoke test

```bash
node apps/api/scripts/r2-smoke.mjs
```

Expects `S3_*` (and optionally Cloudflare API token) in `.env`. Prints bucket name and `SMOKE: OK` — never prints secrets.

## Code paths

- Upload photos → `UploadsService` → `storage.putObject` → signed URL
- Preview / generation JPEGs → `GenerationService` → `putObject`
- PDF → `PdfService` → `putObject`; delivery links → `getSignedGetUrl`
- Fallback only if Head/Create bucket fails → `.local-storage` + `GET /uploads/local`
